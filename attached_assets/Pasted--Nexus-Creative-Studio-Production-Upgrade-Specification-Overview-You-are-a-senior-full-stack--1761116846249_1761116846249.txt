# Nexus Creative Studio - Production Upgrade Specification

## Overview
You are a senior full-stack engineer tasked with transforming the Nexus Creative Studio website from a placeholder-filled prototype into a production-ready, data-driven platform. This upgrade must deliver a professional, performant, and fully functional agency website with real content, working features, and production infrastructure.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS v3+
- **Database:** Supabase (PostgreSQL)
- **Auth & Storage:** Supabase
- **Testing:** Jest (unit) + Playwright (E2E)
- **Monitoring:** Sentry
- **Analytics:** Google Analytics 4
- **CI/CD:** GitHub Actions
- **Hosting:** Vercel
- **State Management:** React Server Components + Client Components (minimal client state)

## Performance Targets
- Lighthouse Score: ≥95 (all categories)
- Largest Contentful Paint (LCP): <2.5s
- Cumulative Layout Shift (CLS): <0.1
- First Input Delay (FID): <100ms
- Time to Interactive (TTI): <3.5s

### 1.2 Database Schema

Create the following tables with proper indexing and RLS policies:

```sql
-- Brands Table
CREATE TABLE brands (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  name TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  summary TEXT,
  description TEXT,
  logo_url TEXT,
  website_url TEXT,
  tagline TEXT,
  metrics JSONB DEFAULT '{}',
  social_links JSONB DEFAULT '{}',
  color_primary TEXT,
  color_secondary TEXT,
  is_active BOOLEAN DEFAULT true,
  display_order INTEGER DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_brands_slug ON brands(slug);
CREATE INDEX idx_brands_active ON brands(is_active);

-- Services Table
CREATE TABLE services (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  description TEXT,
  category TEXT NOT NULL,
  price_base DECIMAL(10,2),
  price_complexity_multiplier JSONB DEFAULT '{"simple": 1.0, "standard": 1.5, "complex": 2.0}',
  features TEXT[],
  deliverables TEXT[],
  timeline_days INTEGER,
  icon_name TEXT,
  is_featured BOOLEAN DEFAULT false,
  brand_id UUID REFERENCES brands(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_services_slug ON services(slug);
CREATE INDEX idx_services_category ON services(category);
CREATE INDEX idx_services_featured ON services(is_featured);

-- Projects Table
CREATE TABLE projects (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  year INTEGER NOT NULL,
  client_name TEXT,
  categories TEXT[] DEFAULT '{}',
  technologies TEXT[] DEFAULT '{}',
  case_study_url TEXT,
  cover_image_url TEXT,
  gallery_images TEXT[] DEFAULT '{}',
  excerpt TEXT,
  description TEXT,
  metrics JSONB DEFAULT '{}',
  testimonial JSONB,
  brand_id UUID REFERENCES brands(id),
  service_id UUID REFERENCES services(id),
  is_featured BOOLEAN DEFAULT false,
  published BOOLEAN DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_projects_slug ON projects(slug);
CREATE INDEX idx_projects_year ON projects(year DESC);
CREATE INDEX idx_projects_featured ON projects(is_featured);
CREATE INDEX idx_projects_published ON projects(published);

-- Site Metrics Table (Singleton)
CREATE TABLE site_metrics (
  id INTEGER PRIMARY KEY DEFAULT 1 CHECK (id = 1),
  revenue_total DECIMAL(12,2) DEFAULT 0,
  projects_total INTEGER DEFAULT 0,
  clients_total INTEGER DEFAULT 0,
  months_in_business INTEGER DEFAULT 0,
  satisfaction_pct DECIMAL(5,2) DEFAULT 100.00,
  success_rate_pct DECIMAL(5,2) DEFAULT 100.00,
  quality_score DECIMAL(3,2) DEFAULT 5.00,
  active_clients INTEGER DEFAULT 0,
  repeat_clients INTEGER DEFAULT 0,
  avg_project_value DECIMAL(10,2) DEFAULT 0,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

INSERT INTO site_metrics (id) VALUES (1);

-- Investment Features Table
CREATE TABLE investment_features (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  label TEXT NOT NULL,
  price_addon DECIMAL(10,2) NOT NULL,
  description TEXT,
  category TEXT,
  enabled BOOLEAN DEFAULT true,
  display_order INTEGER DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_features_enabled ON investment_features(enabled);

-- Navigation Links Table
CREATE TABLE nav_links (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  label TEXT NOT NULL,
  href TEXT NOT NULL,
  external BOOLEAN DEFAULT false,
  icon_name TEXT,
  parent_id UUID REFERENCES nav_links(id),
  display_order INTEGER DEFAULT 0,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_nav_order ON nav_links(display_order);

-- Contact Submissions Table
CREATE TABLE contact_submissions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  company TEXT,
  phone TEXT,
  message TEXT NOT NULL,
  service_interest TEXT,
  budget_range TEXT,
  metadata JSONB DEFAULT '{}',
  status TEXT DEFAULT 'new',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_submissions_status ON contact_submissions(status);
CREATE INDEX idx_submissions_created ON contact_submissions(created_at DESC);

-- Row Level Security Policies
ALTER TABLE brands ENABLE ROW LEVEL SECURITY;
ALTER TABLE services ENABLE ROW LEVEL SECURITY;
ALTER TABLE projects ENABLE ROW LEVEL SECURITY;
ALTER TABLE site_metrics ENABLE ROW LEVEL SECURITY;
ALTER TABLE investment_features ENABLE ROW LEVEL SECURITY;
ALTER TABLE nav_links ENABLE ROW LEVEL SECURITY;
ALTER TABLE contact_submissions ENABLE ROW LEVEL SECURITY;

-- Public read access
CREATE POLICY "Public read brands" ON brands FOR SELECT USING (is_active = true);
CREATE POLICY "Public read services" ON services FOR SELECT USING (true);
CREATE POLICY "Public read projects" ON projects FOR SELECT USING (published = true);
CREATE POLICY "Public read metrics" ON site_metrics FOR SELECT USING (true);
CREATE POLICY "Public read features" ON investment_features FOR SELECT USING (enabled = true);
CREATE POLICY "Public read nav" ON nav_links FOR SELECT USING (is_active = true);

-- Contact submissions: insert only
CREATE POLICY "Public insert submissions" ON contact_submissions FOR INSERT WITH CHECK (true);
```

## Phase 6: Performance Optimization

### 6.1 Image Optimization

- All images via `next/image`
- Define width & height to prevent CLS
- Use `priority` for above-the-fold images
- Lazy load below-the-fold images
- Serve WebP/AVIF formats

- Store in Supabase storage or use Vercel's image optimization

### 6.2 Code Splitting

- Dynamic imports for heavy components
- Route-based code splitting (automatic with App Router)
- Lazy load modals, charts, calculators

// app/layout.tsx
import { Inter } from 'next/font/google';

const inter = Inter({

### 6.4 Caching Strategy

**Server Components:**
```typescript
// Fetch with revalidation
export const revalidate = 3600; // 1 hour

const data = await fetch(url, { 
  next: { revalidate: 3600 } 
});
```

**Incremental Static Regeneration (ISR):**
- Static pages: Home, About, Services index
- ISR pages: Brands, Services detail, Projects (1-hour revalidation)
- Dynamic pages: Contact form (no caching)

**Database Queries:**
- Index all frequently queried columns
- Use `select` to limit returned columns
- Implement pagination for large datasets

### 6.5 Bundle Size

- Remove unused dependencies
- Tree-shake Tailwind (purge unused classes)
- Analyze bundle with `@next/bundle-analyzer`
- Target: <200KB initial JS load

- Use different values for preview/production

### 10.3 Domain Setup

**Steps:**
1. Add custom domain in Vercel dashboard
2. Update DNS records:
   - A record: `76.76.21.21` (Vercel)
   - CNAME: `cname.vercel-dns.com`
3. Enforce HTTPS redirect
4. Set canonical domain (www vs non-www)
